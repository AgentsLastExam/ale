# Lexicon

Normative. Every term below has exactly one meaning.

| Term | Definition | Never |
|---|---|---|
| **Sandbox** | An isolated execution instance supplied for one episode. | never called an Environment |
| **Provider** | A backend adapter that turns a SandboxRequest into a Sandbox holding the guarantees in [the Provider contract](sandbox-image.md#provider-contract), or rejects it before creating anything. | not a model vendor or Task-selected setting |
| **Fleet** | The machines one control plane pools, and the control plane that places Sandboxes on them; [Fleet](fleet.md). | not a warm pool or an environment server: it starts no Sandbox before a request |
| **Node** | One machine that offers its Sandbox capacity to the Fleet. | not the Host that runs a Run and its Gateway, nor a worker of Orchard |
| **Node agent** | The process on a Node that registers it, drives its leaves and holds its Sandboxes' leases. | never a scheduler: it creates only what the control plane granted |
| **FleetProvider** | The scheduler through which a Run's Sandboxes run on the Fleet (`fleet`). | not a Node's leaf, which the node agent drives |
| **Leaf** | A Provider that starts Sandboxes on the machine it runs on, such as `docker:runc`, `qemu` or `orchard`. | never places a Sandbox on another machine |
| **Scheduler** | A Provider that places Sandboxes on machines it manages, which start them with the leaves there, such as `fleet` or `daytona`. One whose leaves are not ALE's, such as Daytona, records itself as the leaf. | never one of its own leaves, and never told by a Run which leaves to use |
| **Provider id** | The name by which a Run's `sandbox.providers`, a Node and a capability profile know a Provider, such as `docker:kata`. | not the prefix of its handles, which is `docker` for every Docker runtime |
| **Capability profile** | One real combination a leaf can start, under its provider id: kind, operating system, architecture, desktop, network modes, snapshots and how many it saves in a row, GPUs, their models and memory and how it shares them, CPU and memory limits, whether it holds a Sandbox to its `storage_mb`, and container features. One rule compares a Sandbox's needs with profiles wherever a Provider or Node is chosen; [Provider selection](sandbox-image.md#provider-selection). | not independent lists of systems and architectures |
| **Container feature** | A kernel feature from a closed set, such as `perf` or `mount`, that a Task's container Sandbox gets only by naming it in `container_features`; [Container features](task-authoring.md#container-features). | never a Provider or runtime a Task names, and never asked of a VM |
| **Model provider** | The vendor whose API the Gateway or a Judge calls, named by `gateway.provider` or a Judge's `provider`. It selects `ALE_<PROVIDER>_API_KEY` and `ALE_<PROVIDER>_BASE_URL`. | never a Sandbox Provider |
| **Episode protocol** | The administration layer that turns one Task into one Episode: provision, setup, agent, validate between turns when the agent receives validation rounds, verify, teardown. | not selected or replaced by a Task |
| **Task folder** | The complete self-contained authored source unit: `task.toml`, instruction, environment, tests, optional validation, calibration cases (the reference solution among them), and optional agent resources. | not dependent on `domain.yaml`, a repository Kit, sibling Task, or shared domain image |
| **Task id** | `[task].name`, Harbor's `org/name` with each part a lowercase slug, unique in its collection. Where it names a file, directory, container or image it is the one component `org.name`. | not derived from the folder path |
| **Environment** | The Task's definition of the machine the agent starts on: `[environment]` and `environment/`. | never a Sandbox or the episode protocol |
| **Task source digest** | A digest of the Task folder's canonical paths, bytes, executable bits, and symlink targets, pruning only the [asset roots](task-assets.md) and generated state. | not a hash of `task.toml` alone or of asset bytes |
| **TaskSpec** | The frozen, serializable specification of one Task: its checked `task.toml` and its instruction. | not the folder on disk |
| **Task operating system** | `linux` (default), or explicit `windows` or `macos`; it selects path and stage-entry semantics and must match the prepared image. | not a Provider name inferred from an image tag |
| **Task** | One self-contained Task folder bound to its TaskSpec and standard behavior. | not a collection or loader |
| **Task collection** | A directory or source that contains several independent Task folders for selection. | not a Task and not an execution contract |
| **Image declaration** | A solver's or dedicated verifier's image as its Task folder states it: an image used directly (`image`), a Dockerfile in its fixed directory, or a VM build script on the base `image` names. Its kind (container or vm) follows from these and the OS, except for a Linux image named alone by a registry reference, which its manifest decides; [Source selection](sandbox-image.md#source-selection-and-identity). | not a Provider selection or build flag |
| **Task image** | The final container or VM image prepared from the Task's own build definition, on its base for a VM build script, or from an image reference used directly. | not a shared Image Tree node |
| **Prepared Task image** | Immutable kind-aware output consumed by a sandbox request. | not mutable sandbox state |
| **ALE base image** | A foundational Ubuntu desktop container, Ubuntu VM disk, or Windows VM disk meeting the sandbox image contract; ALE adds the guest service when it prepares an image. | not a domain image or Task-specific dependency bundle |
| **VM builder** | ALE's versioned image (`ale-vm-materializer`) that edits VM disks offline: it makes the Linux VM base's disk once per version, installs the framework into a disk, and discards a VM build's free space. | not the temporary VM a Task's build script runs in; never Task-authored boot or partition code |
| **Task assets** | Optional ignored files in a Task's [asset roots](task-assets.md), synchronized explicitly with a same-named HF dataset; to the runtime they are ordinary stage files. | not a configuration declaration, central cache tree, content hash, or implicit runtime download |
| **Setup** | Trusted framework-controlled Task work that creates irreducibly per-episode state after the Task image starts. | not package installation, fixed compilation, or fixed input download |
| **Framework Verification Library** (`ale_verify`) | The engine-owned Python package staged for verify; it provides optional checks, Judges returning data, and atomic JSON result writing. | not a repository Kit, Host verification service, Gateway client, or plugin |
| **Judge Invocation** | One attributable LLM or agent Judge execution with its resolved configuration, attempts, usage, verdict, and evidence links. | not a Task configuration declaration or reusable profile |
| **Calibration case** | A known final state and the scores the Task's verifier must give it: every Task's `solution`, its reference solution in `calibration/solution/`, and each further `[[calibration]]` entry's directory there; an entry sets or replaces its expectation, which `ale calibrate` checks; [calibration](task-authoring.md#calibration). | not an evaluated agent's Episode; its expectation never scores an Episode |
| **Validation round** | One run of a Task's `validation/` on the state an agent's turn left, from a snapshot of its solver, whose result and feedback the agent receives as its next turn begins; `[agent].validation_rounds` of them give the agent that many more turns; [Validation rounds](episode-protocol.md#validation-rounds). In specs and Task-facing text, "validation" names this alone. | never `tests/`, which scores the final state once and is never shown |
| **Verification Result** | The Task-authored result in the verifier directory, `reward.json` with an optional complete `verification.json`, saved on the host as `verification.json`; only `reward` has scoring semantics. | not the Episode Result or solver trajectory |
| **Artifact snapshot** | Immutable regular-file/directory solver evidence captured after the solver stops and before verification, with exact source path, type, mode, and content identity. | not post-verifier bytes or an implicit workspace copy |
| **Separate verifier** | A fresh verifier sandbox using reused solver content, a Task-local verifier build, or a resolved external image, with its own or the solver's resources and exact artifact restoration. | not a second setup run or a copy of the whole solver filesystem |
| **Snapshot verifier** | A fresh verifier Sandbox booted from a Sandbox snapshot of its stopped solver, on the leaf that saved it, with its own or the solver's resources; `environment_mode = "snapshot"`. | not a separate verifier: it restores no artifacts and boots from a snapshot, not an image; never the solver's processes |
| **Retained sandbox** | An ALE-managed, sanitized Sandbox kept after its episode when run policy requests `keep`, with a durable Provider handle and cleanup command; reverification and continuation attach to it. | not Task-controlled or an unmanaged leaked container |
| **Sandbox snapshot** | The sanitized disk of a solver saved, with a Provider handle, when run policy requests `snapshot`, durable then, or for a snapshot verifier or a validation round to boot from, destroyed after it unless kept; any number of continuations and verifiers boot new Sandboxes from it. | not an Artifact snapshot, and holds no running process |
| **Episode** | One complete administration of one selected Task instance by one agent. | not a trial or job |
| **Run** | One batch invocation of Episodes plus its Run Status Projection. | — |
| **Harness** | The adapter binding an agent program to ALE. An Autonomous Harness owns its loop; a Policy Harness drives a framework-owned Task environment. | not an agent identity or Task setting |
| **CLI Harness** | An Autonomous Harness that runs one pinned native command-line agent through `CliHarness`, sharing its prompt delivery, evidence layout, and continuation rules. | not a wrapper for arbitrary commands |
| **Harness Preset** | Complete version-controlled configuration automatically selected for one Harness. | not an implicit constructor default |
| **Skill Source** | An operator's explicitly declared local directory containing one Skill or immediate Skill collection. | never ambient host agent state |
| **MCP Server** | A checked stdio or Streamable HTTP server definition made available to an agent. | not a vendor-native config file |
| **Effective Agent Resources** | The Task's Skill directory and MCP servers with the deduplicated preset-, Run-, and CLI-declared ones, which replace a Task's of the same name. | never ambient configuration |
| **CUA Desktop MCP** (`cua-desktop`) | ALE's built-in screen-control MCP server selected at Run level. | not selected by a Task or automatically injected by an image |
| **Desktop resolution** | The size, in logical pixels (points on macOS), that every Sandbox's desktop starts at, set by the Run's `desktop_resolution` and checked by the Provider; [Desktop resolution](sandbox-image.md#desktop-resolution). | never part of a prepared image or its identity, nor the size of the screenshots an agent's tools return |
| **Native Continuation** | One Harness's exact native agent session, by its native ID; it resumes wherever that session's files are, including a later episode's adopted retained solver, one booted from its snapshot, and the next turn's solver after a validation round. | not Run resume, transcript replay, or a copy of the session |
| **Limit Termination** | The recorded layer, limit, configured value, and cause that stopped an Episode. | not an untyped process exit |
| **GuestServer** (`ale-guestd`) | The in-sandbox service through which execution, file transfer, and observation flow. | never Provider-specific |
| **Gateway** | The host-side service through which solver traffic in API-key and subscription modes is controlled, metered, credentialed, and recorded. | Judge traffic is attributed separately from solver traffic |
| **ATIF Trajectory** | The Harbor ATIF v1.8 document containing the complete ordered agent-visible interaction ALE can observe. | not setup, verification internals, or a native transcript |
| **Transport Trace** | The append-only Gateway record of solver model calls, refusals, accounting when available, and trajectory links. | not full conversation storage |
| **Execution Trace** | The append-only record of framework phases, commands, Task-stage output, policies, and diagnostics. | not agent-owned tool activity |
| **Episode Result** | The sole terminal outcome: status, complete named rewards when verified, stats, bounded failure, phase timing, and timestamps. | not a scalar reward |
| **Blob** | An immutable episode-local content-addressed payload referenced by path, media type, size, and digest. | not ordinary short inline text or a Task artifact |
| **Native Log** | A Harness's own record of a run, declared in `Harness.logs`, mirrored to the Host while the agent runs, and parsed into the canonical trajectory. | not canonical while unparsed and not a Task artifact |
| **Run Status Projection** | The rebuildable Run-level view of queued, running, phase, terminal, interrupted, rewards, and bounded failure state. | not an Episode evidence store |
| **RunLock** | Schema-3 provenance binding declaration, prepared image, actual Provider observation, Task, data, agent, framework, and effective configuration to a result. | not a qcow2 byte-hash cache |
| **Workspace** | The image-declared agent home. A relative path in `task.toml` starts at `[agent].workdir` below it; ALE adds no other prefix. | not a repository or fixed framework directory layout |
